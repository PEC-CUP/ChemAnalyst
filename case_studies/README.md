# Case Studies

This directory contains only representative records explicitly referenced by the manuscript and Supporting Information.

- `historical_db/`: Appendix E machine-readable record for historical-database-guided property inference (`petroleum_fraction_db_041`, top-k = 10, GPT-4.1 offline validation).
- `rag_dpf_ms/`: Appendix F DPF-MS analytical-method interpretation case and full RAG route outputs.
- `tool_onboarding_hydrocarbon/`: planner-routed runtime test record for the hydrocarbon-type calculator onboarding example.

Broad intermediate outputs, paper figure drafts, plotting source tables, and batch checkpoints are intentionally excluded from the public release.
